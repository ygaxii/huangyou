亚拉拉特之夜（ARARAT NIGHT）

2026-11-18 合集区
百度夸克

游戏介绍

醒来时，置身于陌生的白色设施之中。3天后，只有通过试炼的人才能离开--男女6人，两两一间卧室度过的3个夜晚。

★故事梗概★

在陌生的白色房间里，6个人醒了过来。

3名男性，3名女性。谁都几乎不记得来到这里之前的事情。

不知从何处，响起了一个声音。

欢迎。你们将在这里挑战试炼。

3天后，只有跨越了试炼的人，才能从这里离开。

白天大家一起解开设施的机关，夜晚则两两一组，分在3间卧室里度过。

今晚，与你同处一间卧室的会是谁？而在墙壁的另一边，又是谁和谁--。

★登场人物★

・艾拉（アイラ） ―― 礼貌端庄的大小姐。小女子名叫艾拉。这里是哪里，小女子也不清楚呢

・琪亚拉（キアラ） ―― 活泼开朗、自来熟，对谁都用平辈语气说话。我叫琪亚拉！虽然这地方怪怪的，不过请多关照啦

・彩香（アヤカ） ―― 让人捉摸不透的神秘仆娘（自称仆的少女）。……仆叫彩香。你们也是，回过神来就在这里了吗？

・约翰（ジョン） ―― 乍看之下很温柔，实际上是个极易出手的轻浮男。

・德雷克（ドレイク） ―― 强势霸道的大男子主义者（硬派强硬系）。

・你 ―― 失去记忆，连自己名字都想不起来的男人。

★游戏系统★

【白天 ―― 调查设施，解开试炼的机关】

苏醒之间、配给室、记录室、鸽子室、祭坛室……设施被划分为好几个房间。

点击物品或人物，进行调查或交谈。

每天都有不同的试炼机关，从线索中弄明白解答方法后，便可以拜托某人一起过来共同挑战。

一天有12个小时。消耗时间的行动，每次耗费1小时。

【好感度，以及四处走动的5人】

通过闲聊或赠送礼物，可以加深与对方的感情。一开始持有的银戒指，只能送给其中的1个人。

每经过1小时，大家就会在设施内四处走动，处于同一房间的人之间的关系也会随之变化。

感情加深的2人，甚至在探索途中，就会在房间的角落里开始亲热起来……。

通过观察情况，可以知道那个人现在最在意谁。

【夜晚 ―― 两两一组，前往3间卧室】

夜晚会根据关系亲密程度决定房间分配，两两一组分到3间卧室。一起跨越试炼的对象，当晚会分在同一间卧室。

和女主角分到同一间卧室后，就在限制时间内触摸她来提升氛围吧。

抚摸、触碰脸颊、抓揉胸部、接吻--不过，如果触碰到还为时尚早的部位，氛围就会下降。

等氛围充分高涨后，选择邀请即可进入2人场景。

什么也没发生的夜晚，可以通过窥视孔偷窥左右两边的卧室。

【2人场景】

以3D角色动作呈现的场景。

视角可以自由移动，也能切换为第一人称、斜上方、侧面、脚边视角。还可以显示断面图。

可以改变速度，在过程中也能触碰身体或接吻。持续接吻的话，会变成舌头交缠的深吻。

2人的高潮槽会不断上升，当你的槽满时便会射精（高潮结束）。

好感度越高，女主角的声音和反应也会随之改变。

【6种结局】

第3天夜晚天亮后的早晨，白色的门会打开吗？如果打开了，又要和谁一起离开？

根据这3天的度过方式，结局会分为6种。甚至也有和3位女主角所有人一起离开的路线。

结局之后，可以查看每位女主角的记录（经历过的次数、对象、体位、肚子里的孩子）。

达成的结局越多，记录中出现的提示就会增加，设施里可供调查的物品也会变多。

★关于R-18场景★

R-18场景是以3D角色动作呈现的画面。

・夜晚的卧室里，与同处一室的女主角

・白天的探索中，与关系要好的女主角（在只有2人的房间里选择在这里邀请等）

・偷窥 ―― 从夜晚隔壁的卧室，或白天设施的掩体暗处

开场方式共有15种。体位有11种、共32种模式（正常位、后背位、骑乘位、背面骑乘位、坐位、立位、站立后入、抱着站立、在椅子上从后面、坐在椅子上、用嘴做）。

射精结束之后，溢出的白色液体会在肌肤上留下痕迹。

男性角色会以淡淡的半透明身体显示。

◆ 开场方式（全15种）

・与你 ―― 在这里邀请 / 在这里邀请（旁边的2人也被带动了） / 换了对象后的邀请 / 往下看时的邀请 / 豁出去的女孩的邀请 / 被抢走了呢 / 让男人介绍 / 破处 / 男人的不嫌弃我用完之后的话

・与其他男性（偷窥）―― 探索中已经开始了 / 探索中2组同时 / 稍微等一下哦 / 希望你陪这孩子玩玩

・夜晚 ―― 夜晚的卧室 / 夜晚隔壁的卧室

本作品包含女主角与你以外的男性发生关系的场面（NTR/寝取要素）。

首次选择从头开始时，可以选择是否关闭（之后也可以在设置的无寝取中进行更改）。

关闭后，就不会发生与其他男性的场面。也有仅不显示探索中其他人之间场面的设置。

观看特定结局后，标题画面会追加相册。

可以选择开场方式、角色、体位、好感度，随时重温。

★收录内容★

・女主角3人（艾拉、琪亚拉、彩香）/ 男性2人（约翰、德雷克）

・体位11种、全32种模式（3D动作）

・开场方式15种（探索中13种、夜晚2种）

・结局6种

・3位女主角均附带语音（对话语音约730条 + 随场景和好感度变化的行为中娇喘声）/ 男性台词仅为文字

・第一人称、自由视角、断面图、窥视孔

・夜晚的氛围，以及过程中也能触碰、接吻的操作

・结局之后的每位女主角记录

・可选择开场方式、角色、体位、好感度重温的相册

・无寝取设置

・每天早上的自动存档（选择继续，从记录那天的早晨开始）

・仅限日语

★游玩时间★

通关（1周目・3天）大约需要1小时，看完所有6种结局大约需要2小时左右。

★运行环境★

・操作系统：Windows 10 / 11（64位）

・显卡：支持 DirectX 11 的 GPU

・容量：下载（zip）约0.8GB / 解压后约1.6GB

・输入设备：鼠标+键盘（也可使用触屏游玩）

・已确认运行环境：Windows 11 / AMD Ryzen 7 9800X3D / 内存 64GB / NVIDIA GeForce RTX 5080

※ 未测试过配置低于此标准的 PC 运行情况。运行卡顿时，降低设置中的画质即可变得流畅。

★关于AI生成★

本作品在剧本、角色语音、部分图像及小物件的3D模型等制作工序中活用了生成式AI。

★注意事项★

本作品为原创作品。登场人物均已年满18岁。

包含女主角与你以外的男性发生关系的场面（寝取要素）。可在设置中关闭。

性器官打有马赛克。

需要使用鼠标（或触屏）进行操作（游戏手柄仅支持2人场景、对话、设置的操作）。
